# Student Management System (Java)

A web-based student management system built using Java Servlets and JSP.

## Features
- User registration and login
- Add, update, and delete student records
- View student details
- Image handling support

## Tech Stack
- Java
- Servlets
- JSP
- HTML/CSS
- Apache Tomcat

## Project Structure
- src/ – backend logic (Servlets & controllers)
- WebContent/ – frontend JSP pages and static assets

## How to Run
1. Import project into Eclipse
2. Configure Apache Tomcat server
3. Deploy and run on server

## Use Case
Can be used in educational institutions to manage student data efficiently.
